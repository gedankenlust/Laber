# Security Policy

## Supported versions

Security fixes are provided for the latest source version on the `main` branch.
Laber is currently pre-1.0 software, so users should update to the newest available version before reporting an issue.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, private customer text, exported backups, or local database files in a public issue.

Use GitHub's private vulnerability reporting for this repository. If that option is unavailable, contact [@gedankenlust](https://github.com/gedankenlust) before sharing technical details publicly.

Include a concise description, affected version, reproduction steps using synthetic data, and the expected impact.
